# Expo PWA + Firebase CRUD

Aplicativo demonstrativo com Expo, React Native Web e Firebase Firestore.

## Checkpoints

1. Preparar o projeto Expo.
2. Configurar PWA: manifest, service worker, build e instalação.
3. Criar duas telas: formulário (Nome, Descrição) e listagem.
4. Conectar Firebase Firestore com regras seguras.
5. Implementar Create e Read.
6. Implementar Update e Delete.
7. Validar CRUD e instalação PWA em HTTPS.

**Estado:** checkpoint 1 preparado, ainda sem validação de execução local. Firebase não configurado.

## Iniciar

```bash
npm install
npx expo start --web
```

Não publique credenciais administrativas ou arquivos .env com segredos.
